# Free Compute

For CPU operations: use local. Nothing better than this. There are also
CPU-only pods that you can get for as little as 3 USD per month. Though, this
should not be required (unless you are running agents 24/7, which I don't see
happening right now).

    - There is also something called "Oracle Free Cloud Tier" which supposedly
      has an always free Linux VM that you can use. Check this out. Really
      helpful for general development!

For GPU/TPU operations: Google Colab. Good thing about this is that you can also
connect it to VSCode.
